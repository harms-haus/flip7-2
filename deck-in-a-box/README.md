# Deck-in-a-Box

A command-line interface for playing BigDeckEnergy card games in the terminal.

## Overview

Deck-in-a-Box is a terminal-based CLI tool that provides an interactive interface for playing card games built with the BigDeckEnergy library. It features a rich terminal UI built with React and Ink.

## Installation

```bash
npm install -g deck-in-a-box
```

## Usage

```bash
# Start the CLI
deck-in-a-box

# Or use the short alias
dib
```

## Features

- Interactive terminal UI
- Support for multiple card games
- Real-time game state visualization
- Colorful terminal output
- Game configuration management

## Available Games

- War
- Go Fish
- Custom games (via configuration)

## Development

```bash
# Install dependencies
npm install

# Build the CLI
npm run build

# Run in development mode
npm run dev

# Run tests
npm run tests
```

## Dependencies

This CLI depends on the `big-deck-energy` library for game logic and state management.
